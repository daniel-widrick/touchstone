Getting started with harbour

harbour makes encrypted, de-duplicated backups of folders to a local disk or to any S3-compatible storage. This page takes you from installing it to a first backup, a restore and a nightly schedule.

What you need

  • One of: macOS 12 or later, Linux with glibc 2.31 or later, or Windows 10 or later.
  • About 60 MB of disk space for harbour itself.
  • No other software. harbour has no dependencies.

Install harbour

macOS

brew install harbour

Linux

curl -fsSL https://get.harbour.example/install.sh | sh

Then check that it installed:

harbour --version

Windows

winget install Harbour.Harbour

Create a repository

A repository is where harbour stores your backups. The commands on this page use /mnt/backup/repo as the repository and ~/Documents as the folder to back up. Replace them with your own paths.

The passphrase cannot be recovered. harbour asks you to choose one when you create the repository. If you lose it, nobody can read your backups, including us. Store it somewhere safe before you go on.

harbour init /mnt/backup/repo

harbour asks for the passphrase twice.

On S3-compatible storage

Set your storage key and secret in the environment first. On macOS or Linux:

export HARBOUR_S3_KEY="your-key"
export HARBOUR_S3_SECRET="your-secret"

On Windows, in PowerShell:

$env:HARBOUR_S3_KEY = "your-key"
$env:HARBOUR_S3_SECRET = "your-secret"

Then create the repository, with your own bucket name and path:

harbour init s3://bucket-name/path

Make a first backup

harbour backup ~/Documents --repo /mnt/backup/repo

The first run copies everything and can take a long time. Later runs send only what changed.

See what is stored

harbour list --repo /mnt/backup/repo

Each backup is called a snapshot and has an id like a1b2c3d4. You need the id to restore.

Restore files

Replace a1b2c3d4 with the id of the snapshot you want, and ~/restored with the folder to restore into.

harbour restore a1b2c3d4 --to ~/restored --repo /mnt/backup/repo

harbour never overwrites existing files unless you add --overwrite.

Back up every night

On Linux or macOS, open your crontab for editing:

crontab -e

Add this line to run a backup every night at 02:00:

0 2 * * * harbour backup ~/Documents --repo /mnt/backup/repo --quiet

Common problems

repository is locked

Another harbour process is using the repository, or one crashed. If you are sure nothing is running, unlock it:

harbour unlock --repo /mnt/backup/repo

wrong passphrase

Check your keyboard layout and caps lock, then try again. The passphrase cannot be reset.

permission denied reading a file

harbour skips the file and carries on, then lists the skipped files at the end. To include them, run the backup with sudo:

sudo harbour backup ~/Documents --repo /mnt/backup/repo
