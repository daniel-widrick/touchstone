Getting started with harbour

harbour makes encrypted, de-duplicated backups of folders to a local disk or to any S3-compatible storage. This page takes you from install to a first backup, a restore and a nightly schedule.

Requirements

  • macOS 12 or later, Linux with glibc 2.31 or later, or Windows 10 or later
  • About 60 MB of disk space

harbour has no other dependencies.

1. Install harbour

macOS

brew install harbour

Linux

curl -fsSL https://get.harbour.example/install.sh | sh

Windows

winget install Harbour.Harbour

Check the install

This prints the installed version.

harbour --version

2. Create a repository

A repository is where harbour stores your backups. The examples on this page use /mnt/backup/repo. Replace it with your own location.

harbour init /mnt/backup/repo

harbour asks for a passphrase twice.

The passphrase cannot be recovered. If you lose it, nobody can read the backups, including us. Store a copy somewhere safe before you go on.

Use S3-compatible storage instead

Set HARBOUR_S3_KEY and HARBOUR_S3_SECRET in your environment, then create the repository with an s3:// address.

harbour init s3://bucket-name/path

3. Make a first backup

This backs up the folder ~/Documents.

harbour backup ~/Documents --repo /mnt/backup/repo

The first run copies everything and can take a long time. Later runs send only what changed.

4. See what is stored

harbour list --repo /mnt/backup/repo

Each backup is called a snapshot and has an id like a1b2c3d4. You need the id to restore.

5. Restore files

Replace a1b2c3d4 with the id of the snapshot you want, and ~/restored with the folder to restore into.

harbour restore a1b2c3d4 --to ~/restored --repo /mnt/backup/repo

harbour never overwrites existing files unless you add --overwrite.

6. Back up every night

On Linux or macOS, add this line to your crontab to run a backup every night at 02:00.

0 2 * * * harbour backup ~/Documents --repo /mnt/backup/repo --quiet

Common problems

repository is locked

Another harbour process is using the repository, or one crashed. If you are sure nothing is running, unlock it.

harbour unlock --repo /mnt/backup/repo

wrong passphrase

Check the keyboard layout and Caps Lock. There is no reset.

permission denied reading a file

harbour skips the file and carries on, then lists the skipped files at the end. To include them, run the backup with sudo.
